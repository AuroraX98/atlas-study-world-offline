# Changes

- Added 96 built-in lessons with difficulty labels, plain explanations, term definitions, examples, understanding checks, and completion rewards.
- Added optional OpenAI, Claude, and DeepSeek study assistance with language-specific lesson choices and response preferences.
- Added a local companion, protected API-key storage in macOS Keychain or Windows Credential Manager, optional permitted JSON key-file access, and provider-specific clearing.
- Improved journal autosave and backups, weekly reports, search, practice/evidence validation, and quest limits.
- Explained island purpose and progression, updated generic prompt wording to AI Assistant, and added language lesson guidance beside the dropdown.
- Included Mac/Windows launchers, quick-start instructions, API-key setup/removal guides, and a verification report.

This preview retains manual checks for Windows hardware, direct HTML-file opening, final PDF output, installed voices, and clean installation. Real DeepSeek lesson generation was checked; OpenAI and Claude requests were checked with mocks.
